# pig-latin-go
This Golang CLI "translates" a text file into either Pig Latin or Feaux Old Norse. You can watch the video of how it was made here: https://www.youtube.com/watch?v=vMyaU7bbxx4

# How To Use
You should be able to just pull it and run it like a normal go program. No weird dependencies or anything.

# Usage
Feel free to fork it and play around with other translator techniques.
